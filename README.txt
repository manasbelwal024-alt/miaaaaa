LOVE LETTER WEBSITE

Files:
- index.html: website structure
- style.css: styling and animations
- script.js: interactions
- Add your own music file named music.mp3 to this same folder.
- Add photos named photo1.jpg through photo6.jpg to this same folder.

Run:
Open index.html in Chrome. The CSS and JavaScript load automatically because
index.html links to style.css and script.js.

Music:
Browsers do not allow autoplay in many cases. Click "Play music" after opening
the page. Use an MP3 file you have permission to use.
